## 运行 Vue

Node.js 版本要求见 vue-day5/package.json（^22.18.0 或 >=24.12.0）。

```sh
cd vue-day5
npm ci
npm run dev
```

构建检查：`npm run build`。按终端显示的本地地址打开页面。

2026-10-09 整理时，依赖安装及构建通过。保留课堂版本的依赖锁文件；当次 npm audit 报告 4 项 high 级别依赖问题，未在归档过程中升级依赖。本仓库用于学习记录，后续继续开发或部署时应先处理依赖问题。

## 运行 Java

在 JDK 17 上验证。

```sh
cd java-day6
javac -encoding UTF-8 GradeHomework.java
java GradeHomework
```

main 中包含九个合法分数和两个非法分数示例；输出用于检查等级边界与范围校验。
